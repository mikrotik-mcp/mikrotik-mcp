Move forward.
With a way back.

Router changes matter. Use the planning workflow to inspect the proposed commands and recovery path before applying them.

  1. Understand the state.

    Start with read-only evidence. Tools carry risk annotations so the client can distinguish inspection from modification.

  2. Review the change.

    Inspect plans, configuration differences and target devices. Keep approval specific to the operation you actually intend.

  3. Apply with safeguards.

    Use supported Safe Mode workflows, snapshots and read-back checks. Limits and uncertain outcomes stay visible; recovery is not a substitute for a backup.

Before you connect

A few good questions.

Does this include an AI model?

No. MikroTik MCP supplies tools and context to your compatible MCP client. The model and its permissions are managed by that client.

Where do my credentials live?

Connection credentials belong in your server configuration or environment. Treat the host and configuration files as sensitive. Only share exports and screenshots after checking them for secrets.

Will connecting change my router?

Not by itself. Read tools inspect state; write tools can modify it. Review client approvals, tool permissions and the selected device before allowing changes.

Which RouterOS versions are supported?

The project supports RouterOS 6 and 7 scopes, but individual tools depend on the installed version, packages and hardware. Check the tool requirements for your router.
