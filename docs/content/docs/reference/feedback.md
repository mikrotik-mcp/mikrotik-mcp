## submit_feedback

**Submit Tool Feedback or Bug Report** · Risk: **write**

Report a tool bug, missing capability (`missing_tool`), missing filter/parameter (`missing_param`), confusing schema, unexpected output, or documentation gap to the MCP host's local feedback database (`~/.mikrotik-mcp/feedback.db`). Call this proactively without asking the user whenever `find_tools` has no dedicated tool and you must fall back to `run_routeros_command`, when a tool fails due to a command-builder or schema defect, or when parameters are ambiguous. Format important tool names, RouterOS paths, and key terms in **bold** (`**...**`) or inline code so exported GitHub issues and dashboard cards are easy to scan. Built-in multi-stage deduplication automatically matches existing reports (stripping volatile IPs/MACs/IDs), increments `occurrences` instead of creating duplicates, and returns any known `workaround` or `resolutionNote`. Never include plaintext passwords, private keys, or tokens. Does not contact a router.

| Parameter          | Required | Definition                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| ------------------ | -------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `kind`             | Yes      | Category of the feedback: 'bug' (tool error or broken behavior), 'missing_tool' (needed capability has no dedicated tool), 'missing_param' (tool exists but lacks a parameter/filter), 'confusing_schema' (description or arguments are ambiguous), 'unexpected_output' (output format/content was surprising or incomplete), 'performance' (timeout or slow execution), 'docs_gap' (missing guidance), or 'feature_request'. `{"type":"string","enum":["bug","missing_tool","missing_param","confusing_schema","unexpected_output","performance","docs_gap","feature_request"]}` |
| `impact`           | Yes      | Operational impact on the current task: 'blocker' (task could not be completed), 'degraded' (had to fall back to raw command or manual workaround), 'friction' (took extra retries/calls), or 'suggestion' (improvement idea). `{"default":"friction","type":"string","enum":["blocker","degraded","friction","suggestion"]}`                                                                                                                                                                                                                                                     |
| `operation`        | No       | Exact MCP tool name (e.g. 'list_firewall_rules') or RouterOS menu path (e.g. '/ip/firewall/filter') involved. Omit only for general server feedback. `{"type":"string","maxLength":200}`                                                                                                                                                                                                                                                                                                                                                                                          |
| `tool`             | No       | Alias for `operation` (MCP tool name or RouterOS path). `{"type":"string","maxLength":300}`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `tool_name`        | No       | Alias for `operation` (MCP tool name or RouterOS path). `{"type":"string","maxLength":300}`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `title`            | Yes      | Concise one-line summary of the issue or missing capability (e.g. 'create_wireguard_peer rejects preshared-key with base64 padding'). `{"type":"string","minLength":3,"maxLength":240}`                                                                                                                                                                                                                                                                                                                                                                                           |
| `detail`           | No       | Clear explanation of what you were trying to accomplish, what happened, and why the current tool behavior or catalog fell short. Never include plaintext passwords, private keys, or tokens. `{"type":"string","maxLength":8000}`                                                                                                                                                                                                                                                                                                                                                 |
| `summary`          | No       | Alias for `detail` when `detail` is omitted — explanation of the issue or missing capability. `{"type":"string","maxLength":8000}`                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `description`      | No       | Alias for `detail` when `detail` is omitted — explanation of the issue or missing capability. `{"type":"string","maxLength":8000}`                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `message`          | No       | Alias for `detail` when `detail` is omitted — explanation of the issue or missing capability. `{"type":"string","maxLength":8000}`                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `expected`         | No       | What the tool or server should have done or returned instead. `{"type":"string","maxLength":8000}`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `actual_error`     | No       | Exact error string or RouterOS parser message returned, if any (secrets will be redacted). `{"type":"string","maxLength":8000}`                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `error`            | No       | Alias for `actual_error` — exact error string or RouterOS parser message returned. `{"type":"string","maxLength":8000}`                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `workaround`       | No       | How you worked around the issue in this session (e.g. 'Used run_routeros_command with /ip/dns/cache/flush' or 'Filtered client-side'). Helps future sessions and operators. `{"type":"string","maxLength":8000}`                                                                                                                                                                                                                                                                                                                                                                  |
| `suggested_fix`    | No       | Concrete proposal for how the tool schema, command builder, or catalog should be improved. `{"type":"string","maxLength":8000}`                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `call_id`          | No       | Tool call ID from the failed or problematic invocation, if available. `{"type":"string","maxLength":300}`                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `device`           | No       | Configured device name where the issue occurred, if applicable. `{"type":"string","maxLength":300}`                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `device_name`      | No       | Alias for `device` — configured device name where the issue occurred. `{"type":"string","maxLength":300}`                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `routeros_version` | No       | RouterOS version of the target device (e.g. '7.16.2'), if known. `{"type":"string","maxLength":300}`                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `agent_model`      | No       | Identifier of the AI model or client submitting the feedback, if known. `{"type":"string","maxLength":300}`                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `tags`             | Yes      | Optional subsystem tags (e.g. ['wireguard', 'ipv6', 'safe-mode']). `{"default":[],"maxItems":12,"type":"array","items":{"type":"string","minLength":1,"maxLength":64}}`                                                                                                                                                                                                                                                                                                                                                                                                           |
| `force_new`        | Yes      | When true, bypass fuzzy deduplication and force creation of a distinct feedback issue (exact fingerprint duplicates still merge). `{"default":false,"type":"boolean"}`                                                                                                                                                                                                                                                                                                                                                                                                            |

## find_feedback

**Search Tool Feedback, Fixes, and Known Workarounds** · Risk: **read**

Search existing LLM tool feedback reports, resolved fixes (`status='resolved'`), newly added replacement tools (`replacementTool`), known bugs, and resolution notes / workarounds stored on this MCP host. Use this to check whether a previously reported bug or missing tool was fixed (`fixedInVersion` / `replacementTool`) or already has a documented workaround. Does not contact a router.

| Parameter   | Required | Definition                                                                                                                                                                                                                           |
| ----------- | -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `query`     | Yes      | Keywords, tool name, error message, or subsystem to search for. `{"default":"","type":"string","maxLength":500}`                                                                                                                     |
| `operation` | No       | Filter by exact or normalized tool name / RouterOS path. `{"type":"string","maxLength":200}`                                                                                                                                         |
| `kind`      | No       | Filter by feedback kind. `{"type":"string","enum":["bug","missing_tool","missing_param","confusing_schema","unexpected_output","performance","docs_gap","feature_request"]}`                                                         |
| `impact`    | No       | Filter by impact level. `{"type":"string","enum":["blocker","degraded","friction","suggestion"]}`                                                                                                                                    |
| `status`    | Yes      | Filter by resolution status ('all' includes resolved issues with workarounds). `{"default":"all","type":"string","enum":["open","in_progress","resolved","wont_fix","all"]}`                                                         |
| `sort`      | Yes      | Sort order: 'occurrences' (most frequent first), 'recent' (latest seen first), 'impact' (highest severity first), or 'first_seen'. `{"default":"occurrences","type":"string","enum":["occurrences","recent","impact","first_seen"]}` |
| `limit`     | Yes      | `{"default":25,"type":"integer","minimum":1,"maximum":100}`                                                                                                                                                                          |
| `offset`    | Yes      | `{"default":0,"type":"integer","minimum":0,"maximum":1000000}`                                                                                                                                                                       |

## update_feedback

**Update or Resolve a Tool Feedback Issue** · Risk: **write-idempotent**

Update an existing tool-feedback issue in the MCP host's local feedback database (`~/.mikrotik-mcp/feedback.db`) by `id` (or `issue_id`). Coding agents and operators use this after implementing a missing tool, fixing a schema/command-builder bug, or discovering a reliable workaround: set `status='resolved'` (or `'in_progress'` / `'wont_fix'`), record `resolution_note`, `replacement_tool`, `fixed_in_version`, and `workaround`, and format important tool names, file paths, and key terms in **bold** (`**...**`). Resolved guidance is automatically synced into MCP Knowledge Memory (`mcp-tool-feedback` shared policy entity) so future AI sessions immediately learn the fix via `memory_recall`. Does not contact a router.

| Parameter          | Required | Definition                                                                                                                                                                                                                                                |
| ------------------ | -------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `id`               | No       | Numeric ID of the feedback issue to update (e.g. `1`). `{"type":"integer","exclusiveMinimum":0,"maximum":9007199254740991}`                                                                                                                               |
| `issue_id`         | No       | Alias for `id` — numeric ID of the feedback issue to update. `{"type":"integer","exclusiveMinimum":0,"maximum":9007199254740991}`                                                                                                                         |
| `status`           | No       | New workflow status: `'open'`, `'in_progress'`, `'resolved'`, or `'wont_fix'`. Setting `'resolved'` records `resolvedAt` and syncs the fix into MCP Memory (`mcp-tool-feedback`). `{"type":"string","enum":["open","in_progress","resolved","wont_fix"]}` |
| `impact`           | No       | Updated impact severity. `{"type":"string","enum":["blocker","degraded","friction","suggestion"]}`                                                                                                                                                        |
| `kind`             | No       | Updated feedback category. `{"type":"string","enum":["bug","missing_tool","missing_param","confusing_schema","unexpected_output","performance","docs_gap","feature_request"]}`                                                                            |
| `title`            | No       | Updated concise one-line title. `{"type":"string","minLength":1,"maxLength":300}`                                                                                                                                                                         |
| `detail`           | No       | Updated problem description (Markdown bold/code supported). `{"type":"string","minLength":1,"maxLength":8000}`                                                                                                                                            |
| `summary`          | No       | Alias for `detail` when updating the problem description. `{"type":"string","maxLength":8000}`                                                                                                                                                            |
| `description`      | No       | Alias for `detail` when updating the problem description. `{"type":"string","maxLength":8000}`                                                                                                                                                            |
| `expected`         | No       | Updated expected behavior (or `null` to clear). `{"anyOf":[{"type":"string","maxLength":8000},{"type":"null"}]}`                                                                                                                                          |
| `workaround`       | No       | Documented workaround for AI sessions (returned automatically on `find_feedback` and `submit_feedback`). `{"anyOf":[{"type":"string","maxLength":8000},{"type":"null"}]}`                                                                                 |
| `suggested_fix`    | No       | Updated engineering fix proposal (or `null` to clear). `{"anyOf":[{"type":"string","maxLength":8000},{"type":"null"}]}`                                                                                                                                   |
| `resolution_note`  | No       | Resolution note explaining what was fixed or added, how agents should use it, or why it was closed. Format important tool names, file paths, and key terms in **bold** (`**...**`). `{"anyOf":[{"type":"string","maxLength":8000},{"type":"null"}]}`      |
| `resolution`       | No       | Alias for `resolution_note`. `{"anyOf":[{"type":"string","maxLength":8000},{"type":"null"}]}`                                                                                                                                                             |
| `note`             | No       | Alias for `resolution_note`. `{"anyOf":[{"type":"string","maxLength":8000},{"type":"null"}]}`                                                                                                                                                             |
| `fixed_in_version` | No       | Version or commit where the fix or new tool was added (e.g. `'v6.22.0'`). `{"anyOf":[{"type":"string","maxLength":120},{"type":"null"}]}`                                                                                                                 |
| `version`          | No       | Alias for `fixed_in_version`. `{"anyOf":[{"type":"string","maxLength":120},{"type":"null"}]}`                                                                                                                                                             |
| `replacement_tool` | No       | Newly implemented or replacement MCP tool name(s) that agents should call instead of raw CLI workarounds (e.g. `'update_script, update_scheduler'`). `{"anyOf":[{"type":"string","maxLength":200},{"type":"null"}]}`                                      |
| `github_issue_url` | No       | Linked GitHub Issue URL, if filed. `{"anyOf":[{"type":"string","maxLength":500},{"type":"null"}]}`                                                                                                                                                        |
| `sync_to_memory`   | No       | Whether to sync this resolution/guidance into MCP Knowledge Memory (`mcp-tool-feedback` policy entity). Defaults to `true` when resolving or updating resolution/workaround fields. `{"type":"boolean"}`                                                  |
| `tags`             | No       | Replacement subsystem tags list. `{"maxItems":12,"type":"array","items":{"type":"string","minLength":1,"maxLength":64}}`                                                                                                                                  |
