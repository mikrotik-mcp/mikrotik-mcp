MikroTik MCP runs on Bun and connects to RouterOS through SSH, with optional REST acceleration and MAC-Telnet discovery paths. It provides a local dashboard and a searchable catalog of risk-annotated tools.

## Start here

1. [Install and verify a connection](/docs/guides/getting-started).
2. [Connect Claude, Codex or another MCP client](/docs/guides/connecting-clients).
3. [Configure multiple devices](/docs/guides/multi-device) and open the [dashboard directory](/docs/dashboard).
4. Before writes, review [Safe Mode](/docs/guides/safe-mode), [backups](/docs/guides/config-snapshots) and [access restrictions](/docs/guides/access-scope-settings).

## Find a feature

- **Dashboard:** a page-by-page directory of controls and reports.
- **Guides:** setup, operational workflows, prerequisites and limits.
- **Tool reference:** every registered module and tool, including input constraints and risk level.

Read-only inspection needs a reachable device and suitable credentials. Configuration changes require the permissions and confirmations described by each tool. A successful command alone does not prove client connectivity.
